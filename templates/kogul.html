PC Agent settings

Server

Restarts the PC Agent process in place so code/template changes take effect, without needing SSH access to whichever machine it's running on (local or VPS).

Weekly pipeline

Businesses to find per Generate click Each click on "Generate" searches for this many NEW businesses and adds them to the list — it no longer caps the week's total, so clicking again keeps growing it.
Partners to reach per category For a category row (not a business row), how many candidate partners to source.
Follow-up timing Fixed: 20h after the partner's last message, while their 24h WhatsApp window is still open, PC Agent sends one nudge written for where the chat stopped, but only if it stalled midway with no clear decision or next step (never on outreach they haven't answered; if it skips, the reason is noted in the chat). Switch to the second number (if any) at 24h, marked unresponsive after 3 days. A partner reply resets it.
Claude model (brand discovery) Used for brand discovery's search/judgment steps only. Real partner replies and Simulate as Partner use OpenAI (gpt-4o) directly, not this — Chat with PC Agent has its own Claude model dropdown on that tab.

Opening message

The exact wording PC Agent sends as its FIRST message to a new partner — use {business_name} and {category} as placeholders. Keep it short — real WhatsApp outreach reads like a text, not an email.

Brief questions

Once a partner is interested, PC Agent asks these one per message, in this order, skipping anything already answered. One question per line. Questions for a single partner are added in that partner's report. A partner with 5 or fewer products is closed politely as Not agreed.

PC Agent's brief (KOGUL.md)

This is read fresh by PC Agent on every message — editing and saving here takes effect immediately, no restart needed.

Partner Central settings

Partner Central team contacts

Human-intervention and partner-agreed alerts go to everyone listed here, by email and WhatsApp. Up to 3 of each.

Emails Where an "agreed" conversation or a human-intervention alert gets emailed.
WhatsApp numbers Same alerts, sent as a real WhatsApp message (E.164, e.g. 94771234567).

WhatsApp sending

Controls whether partner-facing messages (openings, PC Agent replies, nudges, your own messages from Partner Chats) really go out over WhatsApp.

Live sending Off = simulation: every message is only logged and shown as "simulated — not sent". On = messages are really sent to the partner's WhatsApp.
Outreach template name An approved Meta template used when the partner hasn't messaged in the last 24h (the cold opening and the second-number opening; nudges only go out inside the window). WhatsApp rejects plain text there. Leave empty and those sends fail visibly instead.
Template language code The language the template was approved in, e.g. en_US or en.
Template greets by name Tick this if the outreach template has the business name as its one variable, in the header ("Hi {{1}}") or the body. The app then fills it with the partner's name when it sends. Leave unticked for a template with no variable, because WhatsApp rejects values sent to a template that has none.
Team alert template name For alerts to the Partner Central team's own WhatsApp (hot lead, needs a human). WhatsApp only delivers plain text to someone who messaged your business number in the last 24 hours, so register a UTILITY template with one variable, e.g. "PC Agent alert: {{1}}", and put its name here. Empty = plain text, which only arrives inside that 24h window.
Alert template language code The language the alert template was approved in.
